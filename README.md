# 搜索广告终结者

> 作者 [火舞狂沙](https://github.com/zyp1690) ｜ 许可证 [MIT](LICENSE) ｜ 仓库 https://github.com/zyp1690/search-ad-killer

Edge / Chrome 浏览器扩展（Manifest V3），去除 **6 大搜索引擎**结果页中的推广广告。**净化平台与去除类型均可自由勾选**。

> 📖 安装步骤见 [INSTALL.md](INSTALL.md)，或直接用 `dist/` 下的一键安装包。

## 功能特性

- **6 大引擎**：百度、360 搜索、搜狗搜索、必应、Google、DuckDuckGo
- **平台开关矩阵**：一眼看清哪些平台已启用，点击平台名切换其类型配置
- **各平台配置完全独立**：去除类型、自定义选择器互不干扰
- **站点隔离**：百度页面绝不套用搜狗规则，反之亦然
- **3 种处理方式**：折叠提示（推荐，可点击展开）／直接隐藏／彻底删除
- **零闪烁**：内容脚本在 `document_start` 注入样式
- **可无损还原**：完整备份原始内联样式，随时"全部展开"
- **配置导入导出**：多设备同步
- **受保护节点**：搜索框、表单、主容器、body 任何规则都不会隐藏

## 支持平台与默认状态

| 平台         | 域名                                      | 去除类型数 | 默认    |
| ---------- | --------------------------------------- | ----- | ----- |
| 百度         | www/m.baidu.com                         | 12    | 开     |
| 360 搜索     | www/m.so.com                            | 8     | 开     |
| 搜狗搜索       | www/m.sogou.com                         | 7     | 开     |
| 必应         | www/cn.bing.com                         | 4     | 开     |
| Google     | [www.google.com](http://www.google.com) | 4     | **关** |
| DuckDuckGo | duckduckgo.com 等                        | 2     | **关** |

> Google 与 DuckDuckGo 默认关闭：Google 广告判定部分依赖英文文案（`aria-label`、`Sponsored`），国内语料下误判风险更高；DuckDuckGo 国内访问稳定性因网络环境而异。需要时在设置页开启即可。

## 去除类型

每个平台的类型独立配置，规则依据见下方「选择器来源」。

### 百度（12 类）

结果内推广条目（`ec-tuiguang` 角标）、顶部品牌广告、右侧推广栏、横幅图文广告、电商商品推广、原生广告位、聚合榜单、百度动态信息流、悬浮窗广告、AI 智能答案&#x533A;*、相关搜索推广*、广告 iframe*

### 360 搜索（8 类）

品牌广告区（`#so_bd-ad` 品牌臻选）、结果内推广条目（`.e-buss`）、商业推广文字广告（`div[id*="--normal"]`）、右侧推广栏、横幅图文广告、悬浮窗遮罩广告、聚合推荐&#x4F4D;*、广告 iframe*

### 搜狗搜索（7 类）

结果内推广条目（`.ad_result`）、独立广告块（`.js-ad-item`）、顶部品牌广告、右侧推广栏、横幅图文广告、悬浮窗广告、聚合专题推荐*

### 必应（4 类）

结果内赞助条目（`.b_ad`、`aclk?` 付费链接）、右侧推广栏、横幅广告位、商品购物推广*

### Google（4 类）

结果内赞助条目（`.uEierd`、`/aclk?sa=`）、顶部广告条（`#tads`）、商品购物推广、知识聚合模块*

### DuckDuckGo（2 类）

结果内赞助条目（`.result--ad`、`y.js` 跳转）、横幅推广位

> 带 `*` 标记的类型默认关闭：与正常内容边界较模糊，建议按需开启。

## 打包

```bash
python build.py --verify      # 全部产物 + 结构校验
node build-crx.js             # 仅生成 CRX
node verify-crx.js            # 校验 CRX 结构与签名
```

产出到 `dist/`：

| 产物 | 说明 |
|---|---|
| `search-ad-killer-v<版本>.crx` | **拖入浏览器即可安装**，Chrome 推荐 |
| `搜索广告终结者-v<版本>-已解压/` | 免解压目录，Edge 推荐 |
| `search-ad-killer-v<版本>.zip` | 通用分发包，含 `安装说明.txt` |

### 安装 CRX

Chrome：`chrome://extensions/` → 开启「开发者模式」→ **把 .crx 拖进窗口** → 确认「添加扩展」。

Edge 对拖拽 CRX 支持不稳定（常报 `CRX_REQUIRED_PROOF_MISSING`）。若被拦截，请改用免解压目录：`edge://extensions/` → 「开发人员模式」→「加载解压缩的扩展」→ 选文件夹。这是浏览器安全策略，与包本身无关。

### CRX3 实现要点

本项目用 Node 内置 `crypto` 零依赖实现 CRX3 打包（`build-crx.js`）：

- **结构**：`"Cr24"` + version(3) + headerLen + `CrxFileHeader`(protobuf) + zip
- **扩展 ID**：公钥 DER 的 SHA256 前 16 字节，每半字节映射到 `a`~`p`
- **签名**：`RSA-SHA256(crx_id ‖ zip)`
- **密钥持久化**：`.crx-key.pem`。删除后扩展 ID 会改变，**无法覆盖升级已有安装**，务必备份

`verify-crx.js` 会逐字节反解 protobuf、验签，并解压后跑完整测试（19 项校验）。

> ⚠️ `.crx-key.pem` 是扩展身份凭据，已加入 `.gitignore`，切勿分享或提交。

### 打包校验

`--verify` 做 8 项：manifest 在根 / 路径分隔符 / 无开发文件残留 / 安装说明存在 / 解压后引用完整 / manifest 可解析 / 免解压目录结构 / 免解压目录引用完整。

自动处理的坑：`manifest.json` 必须在包根；压缩包内路径强制正斜杠（Windows 反斜杠会导致加载失败）；自动解析 manifest 与 HTML 中所有 `src`/`href`，缺文件即中止打包。

## 安装（Edge）

1. 用 `dist/` 下的免解压目录，或把 zip 解压到任意目录
2. 打开 `edge://extensions/`
3. 开启左下角「开发人员模式」
4. 点击「加载解压缩的扩展」
5. 选择含 `manifest.json` 的那一层文件夹

Chrome 同理，地址为 `chrome://extensions/`。

升级版本后在扩展卡片上点「刷新」即可，无需重装。**旧版配置会自动迁移**，原有设置保留。

## 使用

设置页「净化平台与类型」分两层：

1. **平台卡片矩阵** — 6 张卡片静态内置，每个有两个控件：
   - 左侧**复选框**：勾选 = 加入本次配置（可多选）
   - 右侧**开关**：启用 / 停用该平台的净化
   - 停用净化会自动移出配置集；下方提供「全选平台 / 仅保留常用」快捷操作
2. **类型配置区** — 为所有已勾选的平台配置广告类型：
   - 多平台时按「类型 id」取并集，只在任一选中平台存在的类型才会出现
   - 复选框**三态**：全开 ✓ / 全关 ☐ / 部分开启（半选态）
   - 每个类型后显示 `已开启/持有平台数` 与平台短名标记
   - 「全选 / 仅安全项 / 全不选」批量应用到所有选中平台

**自定义规则**（跨平台共享）：点击「+ 添加规则」，填入 CSS 选择器后，用下方的平台 chips 勾选它适用的平台。一条规则可同时作用于多个平台，无需重复书写。chips 里的「全部」可一键应用到所有平台。

> 注释写法：每条规则一行独立输入框，以 `//` 或 `/*` 开头视为注释。  
> **`#` 开头的选择器是合法的 ID 选择器**，不会被当作注释丢弃。

popup 会自动识别当前标签页所在平台，只显示该平台的开关。

## 数据迁移

配置自动向后兼容，用户升级无感：

- **v1 → v2**：旧的顶层 `types` / `customSelectors` 自动归入百度站点
- **v2 → v3**：旧的「每平台一个 customSelectors 字符串」自动迁移为跨平台规则数组，原平台归属保留

## 选择器来源

跨引擎选择器主要依据 **AdCleaner 规格书 8.3 节**（来源 EasyList China / AdGuard Chinese，规格标注"已核对"）。360 与百度的规则基于公开维护的去广告脚本并结合各引擎广告产品线补充。

搜索引擎会不定期改版。若某类广告不再被清理：在设置页开启「调试模式」定位新选择器，补充到对应平台的「自定义选择器」中即可。

## 说明

- 仅在搜索页生效；图片、地图、资讯、视频等子站自动排除
- 内容脚本对**搜索框、表单、主容器、body** 有硬性保护
- Google 的广告部分封装在 Shadow DOM 中（`bing-ai-card` 类结构），本扩展无法穿透，这是浏览器安全机制的固有限制
